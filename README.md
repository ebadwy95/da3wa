# IZEMAK Clone — بروتوتايب نظام دعوات الأفراح

بروتوتايب شغال (Next.js) بيحاكي نفس الفكرة اللي شفتها في `izemak-platform`:
دعوة شخصية لكل ضيف، تأكيد حضور بحد أقصى للعدد، QR للدخول، محاكاة رسائل
واتساب، سكانر للباب، وتقرير لحظي للعروسين.

## تشغيل المشروع محليًا

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`:

- **`/admin`** — لوحة تحكم العروسين: ضيف ضيف جديد (اسم + تليفون + أقصى عدد)،
  هياخد رابط دعوة شخصي فريد. هتشوف هنا كل الإحصائيات لحظة بلحظة + Feed
  محاكاة رسائل الواتساب.
- **`/invite/[id]?t=token`** — الدعوة الشخصية اللي بتتبعت لكل ضيف. بتفتح
  بأنيميشن بسيط، وبتوريله اسمه وحد أقصى للعدد يقدر يأكده، وبعد التأكيد
  بيظهرله QR Code فوري + رسايل محاكاة إنها اتبعتت واتساب.
- **`/scan`** — صفحة سكانر الباب (بتستخدم كاميرا الموبايل فعليًا عن طريق
  html5-qrcode). لو مفيش كاميرا متاحة (زي بيئة تجريبية)، فيه أزرار "سكان
  تجريبي" بتحاكي نفس العملية.

## إزاي شغال من جوه

- **قاعدة بيانات**: ملف JSON بسيط (`data/db.json`) عن طريق `lowdb` —
  كفاية للتجربة، لكن في الإنتاج لازم تتحول لقاعدة بيانات حقيقية
  (Postgres عن طريق Supabase/Neon مثلًا، أو Firebase).
- **الرابط الشخصي**: كل ضيف بياخد `id` + `token` سري. الرابط بيتحقق من
  الـ token قبل ما يورّي بيانات الضيف، عشان محدش يقدر يخمن روابط ضيوف
  تانيين.
- **QR Code**: بيتولد سيرفر-سايد (`/api/qr`) ومشفر جواه `{id, token}`،
  وده اللي بيتقرا وقت السكان للتحقق من الدخول.
- **رسائل واتساب**: دلوقتي *محاكاة فقط* — بتتسجل في `data/db.json` وبتظهر
  كـ Feed في لوحة التحكم بدل ما تتبعت فعليًا. القسم اللي تحت بيشرح
  إزاي تفعّلها فعليًا.

## نشر مجاني على Vercel (من المتصفح بس، من غير تثبيت حاجة)

المشروع دلوقتي بيدعم Upstash Redis تلقائيًا (مجاني على Vercel) — لو
موجود، البيانات هتفضل محفوظة فعليًا بعد النشر. لو مش موجود، هيرجع
يستخدم ملف JSON المحلي (شغال بس وقت `npm run dev`، مش موثوق بعد النشر
لأن السيرفرات الـ serverless مالهاش تخزين دائم).

خطوات النشر:

1. اعمل حساب مجاني على [github.com](https://github.com/signup) لو
   معندكش، وسيب موجود لو عندك بالفعل.
2. اعمل Repository جديد فاضي (New repository)، من غير README.
3. من صفحة الـ Repo، دوس على "uploading an existing file"، وسحب كل
   محتويات المجلد ده (ما عدا `node_modules` و `.next` — أصلاً مش
   موجودين في الملف المضغوط) وارفعهم، وعمل Commit.
4. روح [vercel.com](https://vercel.com) واعمل حساب مجاني بزرار
   "Continue with GitHub".
5. من الداشبورد، "Add New" → "Project"، اختار الـ Repo اللي رفعته،
   ودوس "Deploy". هياخد حوالي دقيقة وهيديك لينك عام زي
   `your-project.vercel.app`.
6. (اختياري بس مهم عشان البيانات تفضل محفوظة): من صفحة المشروع في
   Vercel → تاب "Storage" → "Marketplace Database Providers" → اختار
   "Upstash" → أنشئ قاعدة بيانات Redis مجانية → دوس "Connect to
   Project". ده هيضيف الـ environment variables تلقائيًا، وبعدها
   المشروع هيعيد النشر لوحده ويبقى شغال بالتخزين الحقيقي.

## عشان تبقى منتج حقيقي (Production-ready)

1. **واتساب فعلي**: هتحتاج WhatsApp Business Platform API — إما مباشرة
   من Meta (Cloud API) أو عن طريق موفر زي Twilio / 360dialog / Wati /
   Gupshup. محتاج:
   - رقم واتساب بيزنس متحقق منه (Business Verification عند ميتا).
   - رسائل Template معتمدة من ميتا (تأكيد الحضور، إرسال QR، تذكير قبل
     الفرح) لأن أي رسالة أول تواصل لازم تكون Template مش رسالة حرة.
   - Webhook يستقبل ردود الضيوف (لو حبيت تضيف تفاعل ثنائي الاتجاه).
2. **جدولة الرسائل**: التأخير اللي شفته (نص ساعة – ساعة قبل ما يوصل QR،
   والتذكير قبل الفرح بيوم) محتاج Job Queue / Scheduler (زي
   `Vercel Cron` أو `BullMQ` مع Redis) بدل ما يبقى فوري.
3. **قاعدة بيانات حقيقية + Auth للعروسين**: كل عريس/عروسة يعمل حساب
   ويشوف بس الأفراح بتاعته (Multi-tenant).
4. **الاستضافة**: أسهل حاجة تنشر بيها Next.js هي Vercel — نفس المنصة
   اللي الموقع الأصلي شغال عليها (`izemak-platform.vercel.app`).
5. **تحسينات تنافسية عن الأصلي**:
   - سجل تهاني (Guestbook) حقيقي بالفيديو/الصوت مش بس نص.
   - إحصائيات أدق: نسبة الحضور المتوقعة حسب تاريخ التأكيد.
   - دعم أكتر من قاعة/عرس في نفس الحساب (لو هتبيعها كبيزنس).
   - لغتين (عربي/إنجليزي) — الأصلي عنده زرار EN لكن يفضل يتفعّل فعليًا.

## هيكل الملفات المهمة

```
src/app/admin/page.js         لوحة تحكم العروسين
src/app/invite/[id]/page.js   صفحة الدعوة الشخصية للضيف
src/app/scan/page.js          سكانر الباب
src/app/api/guests/           إدارة الضيوف
src/app/api/rsvp/[id]/        تأكيد الحضور
src/app/api/checkin/          تسجيل الدخول بالـ QR
src/app/api/qr/               توليد صورة QR
src/lib/db.js                 طبقة قاعدة البيانات (JSON)
```
